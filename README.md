**Retail Business Intelligence: Sales Analysis

Project Overview**
This project analyses retail transaction data to identify sales trends, top-performing products, customer purchasing patterns, and country-level revenue performance.

**Objectives**
- Analyse overall sales performance and key business KPIs.
- Identify monthly revenue trends.
- Determine the best-performing products.
- Compare revenue across countries.
- Examine customer purchasing behaviour.
- Generate actionable business insights.

**Tools and Technologies**
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SQL using DuckDB
- Google Colab
- GitHub

**Methodology**
1. Load and inspect the retail transaction dataset.
2. Clean the data by handling missing values, duplicates, cancellations, and invalid transactions.
3. Calculate revenue using quantity multiplied by unit price.
4. Perform exploratory data analysis.
5. Use SQL queries to analyse sales, products, countries, and customers.
6. Summarise findings and develop business recommendations.

**Key Deliverables**
- Python analysis notebook
- SQL analysis queries
- Sales analysis charts
- Summary CSV files
- Business findings report

**Business Value**
The analysis can help a retail business understand revenue trends, identify products that contribute significantly to sales, compare market performance, and support data-driven decisions.

**How to Use**
1. Open the `.ipynb` notebook in Google Colab.
2. Upload the dataset required by the notebook.
3. Run the notebook cells in order.
4. Review the charts, analysis outputs, and business findings.

**Project Status**
Completed as a portfolio project in data analytics.

**Note:** The findings and recommendations should be interpreted based on the dataset and analysis outputs included in this repository.
